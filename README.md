# ⭐ Funcionalidades
🎸 Afinador — afinação de instrumentos utilizando o microfone do dispositivo.  
🥁 Metrônomo — controle de BPM para auxiliar na prática musical.  
🎼 Cifras — pesquisa e visualização de cifras.  
🔎 Busca — encontre músicas e artistas rapidamente.  
👤 Contas de usuário — cadastro e autenticação.  
👤 Contas de administrador — contas para administrador, podendo adicionar, editar e excluir as músicas de forma on-line.  
📱 PWA — possibilidade de instalar o Riffly como aplicativo.  
🛠️ Área administrativa — gerenciamento do conteúdo da plataforma on-line.

# 📂 Como executar localmente
1. Clone o repositório
```
git clone https://github.com/marcospmtech/riffly
```

2. entre na pasta
```
cd riffly
```

3. Instale as dependências
```
npm install
```

4. Configure as variáveis de ambiente  
Crie um arquivo .env com as configurações necessárias para o funcionamento do projeto.

5. Inicie o servidor
```
npm start
```
Depois acesse o endereço local disponibilizado pelo servidor.

# 📱 PWA

O Riffly possui suporte a Progressive Web App, permitindo que a plataforma seja instalada em dispositivos compatíveis e utilizada de maneira semelhante a um aplicativo.
